Вивчення CSS властивостей

display: block

Перший блоковий елемент Другий блоковий елемент

Після застосування display: block кожен елемент займає окремий рядок і доступну ширину.

display: inline

Перший елемент
Другий елемент

Після застосування display: inline блокові елементи розташовуються в одному рядку. Властивості width і height для них не працюють.

display: flex

Елемент 2

Властивість display: flex розташувала дочірні елементи в один рядок і дозволила керувати відстанню між ними.

border-box

За значення content-box padding і border додаються до заданої ширини елемента. За значення border-box вони вже входять у його загальну ширину.
