Позиціонування елементів у CSS

1. position: static

Static

Це стандартне позиціонування. Елемент розташовується у звичайному порядку сторінки.

2. position: relative

Relative

Елемент зміщений від свого початкового місця, але його місце на сторінці зберігається.

3. position: absolute

Батьківський елемент — position: relative
Absolute

Absolute-елемент розташовується відносно найближчого предка з указаним позиціонуванням.

position: sticky — прокрути сторінку

Sticky-елемент рухається разом зі сторінкою, але після досягнення вказаної позиції тимчасово «прилипає».

Різниця між fixed та sticky

Fixed завжди залишається на одному місці відносно вікна браузера.

Sticky спочатку знаходиться у звичайному потоці сторінки, а під час прокручування прилипає до зазначеної позиції лише в межах свого контейнера.
